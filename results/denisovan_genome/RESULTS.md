# Denisova 3 genome run

## Primary result

- Target: `Denisova3.DG` (AADR assessment `Pass`, coverage 30.7x).
- Autosome callability: 99.89% (1,149,356 1240K sites).
- Alternate diploid-call concordance: 99.90% across 1,061,313 joint calls.
- Same-specimen `Denisova.SG` technical concordance: 98.61% across 574,164 joint calls.
- Denisovan-vs-Neanderthal contrast: D=0.948634, Z=194.35, n=561,674.
- Transversions-only repeat: D=0.957149, Z=147.59, n=104,388.
- Reference-defined Denisovan marker allele: 90.73% across 12,180 callable markers.
- Denisova 11 F1 control: Neanderthal-parent Z=87.57; Denisovan-parent Z=54.67.
- Provisional Denisova 25 has more Neanderthal-related sharing than Denisova 3: D=0.127997, Z=4.64; transversions Z=2.99.

## Interpretation

The run strongly and robustly places the target on the Denisovan side of the
Denisovan-Neanderthal contrast.  The known Denisova 11 F1 recovers both parental
signals, providing an internal biological control.  The same-specimen replicate
is a technical validation only. Its balance test is significantly non-null
(all-SNP Z=13.99; transversions Z=3.61), exposing a
call-set/coverage asymmetry between dense diploid and pseudo-haploid data. It
must not be treated as independent quantitative calibration.

No Denisovan ancestry percentage is reported.  `Denisova.SG` and `Denisova3.DG` are
different AADR call sets from the same Denisova 3 specimen, and the panel does not
provide an independent second high-quality Denisovan calibration genome for an
absolute fraction. Reference-defined marker sharing is a fingerprint, not a
percentage of ancestry.
