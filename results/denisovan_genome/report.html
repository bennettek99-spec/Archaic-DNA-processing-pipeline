Result in plain language

  • The primary input is Denisova3.DG, a 30.7x AADR diploid call set with 99.89% autosomal 1240K callability and assessment Pass.
  • The alternate diploid Denisova3_snpAD.DG calls agree at 99.90% of 1,061,313 joint sites. The lower-density pseudo-haploid Denisova.SG representation agrees at 98.61% of 574,164 joint sites.
  • The dense-diploid versus pseudo-haploid replicate-balance test is not null: D=0.37795, Z=13.99; transversions D=0.19364, Z=3.61. This exposes call-set/coverage asymmetry and is why the same-specimen replicate is not used as an independent quantitative calibration.
  • The Denisovan-vs-Neanderthal lineage contrast is D=0.9486 (Z=194.3, 561,674 SNPs) and remains D=0.9571 (Z=147.6) using transversions only.
  • The known Denisova 11 F1 control independently recovers both parents: Neanderthal-parent Z=87.6 and Denisovan-parent Z=54.7.
  • The provisional ~185 ka Denisova 25 call set is Denisovan-side in the same contrast (D=0.8132, Z=80.9). It also shows more Neanderthal-related sharing than Denisova 3 (D=0.1280, Z=4.64; transversions Z=2.99). These are useful internal signals but remain provisional because its AADR assessment and source publication are provisional.
  • The French negative control is null on the full panel (D=-0.0016, Z=-0.44) but shifts positive in the smaller transversion subset (D=0.0155, Z=2.45). The primary lineage conclusions are far larger and stable, but subtle transversion-only effects should not be overread.
  • No Denisovan ancestry percentage is reported. The primary Denisovan reference and target are the same specimen in different call sets, and the pipeline has no independent second Denisovan calibration genome suitable for an absolute fraction.
Interpretation boundary: reference-defined marker sharing and archaic-axis scores are fingerprints, not ancestry percentages. The same biological Denisova 3 specimen appears as both the target and a technical replicate, so those comparisons validate data handling rather than independently proving Denisovan identity.
