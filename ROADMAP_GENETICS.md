# Genetics roadmap

This keeps the scientific scope versioned so the pipeline does not mix validated
modules, exploratory case studies, and separate species work.

## V1 - validated Eurasian introgression module

Status: implemented / active. Core deliverables are Phase 1 validation, Phase
2-9 AADR processing, PCA projection, f4-ratio and D-statistics, frozen sample
manifest, cohort rules, duplicate-library filtering, validation metrics, and
robustness perturbations.

## V2 - rigorous Etruscan case study

Status: implemented as a focused sub-study, still data-dependent. Cohorts are
assigned by predefined archaeological rules, qpAdm targets are now drawn from
those rules, and duplicate libraries are removed before population tests. The
remaining publication-grade work is full qpWave/qpAdm cross-checking in
ADMIXTOOLS 2 and expanded rejected-model reporting.

## V3 - genome-wide global migration analysis

Status: exploratory. The global AADR mode and whole-panel archaic survey exist,
but a global migration paper needs separate source/target definitions, qpWave
rank tests, transversion-only robustness, and clear continent/period-specific
model rejection tables.

## V4 - canid work

Status: separate repository. Keep canid analyses out of this human AADR pipeline
so reference panels, contamination assumptions, population models, and reporting
do not get entangled.
