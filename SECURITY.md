# Security policy

## Supported versions

Security and data-integrity fixes are applied to the latest release and the
default branch.

## Reporting a vulnerability

Do not open a public issue for a vulnerability involving arbitrary command
execution, unsafe archive handling, dependency compromise, path traversal,
sensitive local paths, or accidental inclusion of personal genotype data.

Use GitHub's private vulnerability reporting for this repository when
available. If it is unavailable, contact the repository owner through the
private contact method listed on the owner's GitHub profile.

Include the affected command, version or commit, reproduction steps, impact,
and any suggested mitigation. Do not attach personal genomic data.

## Data privacy

This repository is intended for public ancient-genomics data and documented
reference datasets. Never commit consumer DNA files, identifiable participant
genotypes, credentials, access tokens, or machine-local configuration.
